# tasktogether

A fullstack task app, kept as a template for new projects. Bun monorepo (Bun >= 1.4).

| Workspace | Purpose |
| --- | --- |
| `@tasktogether/app` | Frontend |
| `@tasktogether/service` | Backend |

```bash
bun install
bun run dev        # runs every workspace's dev script
bun run typecheck
bun test
```
